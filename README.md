ROW Restaurant
مطعم راقٍ يقدّم أفضل المأكولات والمشروبات في أجواء أنيقة ومريحة، مع خدمة ممتازة وتجربة طعام فاخرة تناسب كل الأذواق.

## PostgreSQL

انسخ `.env.example` إلى `.env` وضع رابط PostgreSQL في `DATABASE_URL`.

للتطوير شغّل الخادم والواجهة في نافذتين:

```bash
npm run api
npm run dev
```

للتشغيل بعد النشر:

```bash
npm run build
npm start
```

الخادم ينشئ جدول `restaurant_state` تلقائيًا ويحفظ بيانات المطعم المركزية، لذلك تظهر تعديلات لوحة التحكم لجميع الزوار.
